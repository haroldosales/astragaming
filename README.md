## Astra Gaming

Painel Next.js para gerenciar as categorias e funções do torneio. A página de draft original está disponível em `/draft.html`.

### Desenvolvimento

```bash
npm run dev
```

Categorias são armazenadas no `localStorage` do navegador. Ícones de função: [RivalSkins](https://rivalskins.com/assets/role-icons/).
